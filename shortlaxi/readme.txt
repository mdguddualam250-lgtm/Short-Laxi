A mobile-first editorial block theme for Shortlaxi, a global English-language publication.

== Description ==

Shortlaxi is a block (full site editing) theme built for news and long-form reading:

* Front page with a lead story, a "Top stories" rail and a paginated "Latest" grid.
* Article template with section kicker, byline, reading time, breadcrumbs, author box, previous/next links, comments and "More from Shortlaxi".
* Archive, search, page, "Page without title" and 404 templates.
* Fluid type and spacing scales; one column on phones, up to three on desktop.
* System font stacks only: no web-font downloads, fast first paint.
* "Night" dark style variation, plus "Kicker" (headings/paragraphs) and "Standfirst" (paragraphs) block styles.
